# 📋 Mẫu Phân Rã Dự Án (DAG Task Breakdown Template)

```
[Goal: Tên mục tiêu lớn của dự án]
  │
  ├── [Task 1: Spec & Requirements (Hermes)] 
  │     └── Acceptance Criteria: Tiêu chí nghiệm thu rõ ràng
  │
  ├── [Task 2: Task Breakdown & DAG (DSH)]
  │     └── Danh sách các task con độc lập
  │
  ├── [Task 3: Implementation & Code (Dev Automation)]
  │     └── Test TDD viết trước, code pass test viết sau
  │
  ├── [Task 4: Safety & Quality Audit (JEV Sentinel)]
  │     └── Kiểm tra bảo mật và không có rủi ro phá hủy
  │
  └── [Task 5: Deploy & Ship (OpenClaw Executor)]
        └── Verify kết quả thực tế và commit Git nguyên tử
```
