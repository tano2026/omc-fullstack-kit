# 🧠 Nguyên Lý Hoạt Động Quad-Engine (Trio + JEV)

Hệ thống hoạt động theo mô hình phối hợp 4 động cơ:

1. **JEV Ingress Gate (10ms Reflex):** Tiếp nhận tín hiệu từ bên ngoài, phân tích ngữ nghĩa System 1 cực nhanh và chuyển đúng agent.
2. **DSH Planning Engine (System 2 Strategy):** Lập kế hoạch phi tuần hoàn có hướng (DAG), phân tách việc lớn thành việc nhỏ có thể kiểm chứng.
3. **Hermes Deep Reasoner (System 2 Depth):** Phân tích kiến trúc, thuật toán, tư duy đa chiều và ra quyết định kỹ thuật bền vững.
4. **OpenClaw Execution Commander (System 1 Action):** Thực thi lệnh terminal, build test, git commit, tự động hồi phục khi gặp lỗi.
5. **JEV Safety Guard (Zero-Damage Defense):** Đứng chắn trước mọi thao tác ghi/xóa/deploy để bảo vệ dữ liệu tuyệt đối.
